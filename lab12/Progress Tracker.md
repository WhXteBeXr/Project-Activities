## 📌 Описание

**Progress Tracker** — это приложение для отслеживания личного прогресса в различных сферах: обучение, спорт, привычки и проекты.

Проект позволяет пользователю фиксировать ежедневные достижения и анализировать динамику роста 📈.

---

## 🎯 Цель проекта

Основная цель — помочь пользователю:
- систематизировать задачи
- отслеживать результаты
- повышать продуктивность

*Дополнительно*: приложение ориентировано на минимализм и удобство использования.

## 🚀 Установка

1. Склонируйте репозиторий:

```bash
    git clone https://github.com/example/progress-tracker.git
```

2. Перейдите в папку проекта:
   
```bash
    cd progress-tracker
```

3. Установите зависимости:

```bash
    npm install
```

4. Запустите приложение:

```bash
    npm start
```

## 💻 Пример использования

Пример функции для добавления задачи:

```javascript
function addTask(taskName) {
  const task = {
    name: taskName,
    completed: false
  };
  console.log("Задача добавлена:", task);
}
```

Использование inline-кода: функция `addTask()` добавляет новую задачу.
