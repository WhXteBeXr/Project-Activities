## 📚 Контрольные вопросы

### 1. Чем отличается вложенная цитата от обычной?

Обычная цитата оформляется одним символом `>`:

```md
> Это обычная цитата
```

Вложенная цитата — это цитата внутри цитаты, добавляется дополнительный `>`:

```md
> Это первый уровень
>> Это вложенная цитата
```

📌 Разница в уровне вложенности: вложенная цитата используется для отображения иерархии или диалога.

---

### 2. Как сделать сноску в Markdown и где она отображается?

Сноска создаётся в два этапа:

1. В тексте:

```md
Текст со сноской[^1]
```

2. Внизу документа:


```md
[^1]: Текст пояснения
```

📌 Отображается обычно в конце документа (или блока), где собраны все сноски.

---

### 3. В чём разница между `- [ ]` и `- [x]` в списках задач?

- `- [ ]` — невыполненная задача
- `- [x]` — выполненная задача

Пример:

- [ ] Сделать задание
- [x] Прочитать теорию

📌 Используются для отображения прогресса выполнения задач.

---

### 4. Какие два способа вставки эмодзи вы знаете?

1. Через короткие коды:

```md
:smile:
```

2. Прямой вставкой символа:

```md
😄
```

📌 Первый способ удобен в редакторах, второй — быстрее и нагляднее.

---

### 5. Зачем нужны HTML-вставки? Приведите пример.

HTML-вставки позволяют использовать возможности, которых нет в стандартном Markdown:

- настройка выравнивания
- изменение размеров изображений
- добавление интерактивных элементов

Пример:

```html
<p align="center">Текст по центру</p>
```

📌 Это расширяет возможности оформления документа.

---

### 6. Почему важно использовать правильные имена для внутренних ссылок (якорей)?

Внутренние ссылки (якоря) позволяют быстро переходить к разделам документа.

Пример:

```md
[Перейти к установке](#-установка)
```

Если имя якоря указано неправильно:
- ссылка не будет работать
- пользователь не попадёт в нужный раздел

📌 Это ухудшает навигацию и восприятие документа.

---

### 7. Что произойдёт, если в таблице окажется разное количество столбцов в разных строках?

Markdown попытается отобразить таблицу, но:
- структура может "сломаться"
- данные съедут по колонкам
- часть информации может отображаться некорректно

Пример ошибки:

```md
| Имя | Возраст |
|-----|---------|
| Иван | 20 |
| Анна |
```

📌 Вторая строка будет отображена неправильно.
